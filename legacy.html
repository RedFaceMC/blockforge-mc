Loader guide

Which loader do I need?

Every listing shows its required loader up front, so you know exactly what to install before downloading.

F
Forge

The original, most widely supported Java mod loader — the largest back-catalog of mods.

Fb
Fabric

Lightweight and fast-updating, popular for performance mods and early support for new versions.

NF
NeoForge

A modern fork of Forge built for long-term compatibility with newer mod APIs.

Q
Quilt

A community-driven fork of Fabric focused on modularity and expanded modding tools.

Op
Optifine

A standalone optimization and shader-support tool, often used alongside or instead of a full loader.

P/S
Paper / Spigot

Server software for running plugins that extend multiplayer without any client-side mods.

V
Vanilla / Any

No loader needed — resource packs, maps and datapacks that run on the base game.

Be
Bedrock

Add-ons built for the Bedrock Engine edition, used across console, mobile and Windows.
